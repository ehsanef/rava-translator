# Rava · راوا

ترجمه، به زبان خودت. نسخهٔ ۱.۲.۰ برای Chrome دسکتاپ.

**ساخته‌شده توسط [Ehsanef](https://github.com/ehsanef)**

مدل پیش‌فرض: `gemini-3.7-flash`.

اگر نسخهٔ قبلی را نصب کرده‌ای، [راهنمای به‌روزرسانی](UPDATE-fa.md) را ببین: فایل‌ها را جایگزین کن، افزونه را Reload کن و تب سایت را Refresh کن.

راوا متن انتخاب‌شده را با کلید Gemini خودت ترجمه می‌کند: با لحن توییتری، خودمونی، روان یا رسمی. بدون سرور واسطه، بدون ابزار ساخت و بدون کتابخانهٔ بیرونی.

## نصب روی کروم

1. اگر فایل ZIP را داری، آن را کامل Extract کن. اگر پوشهٔ آمادهٔ `Rava` را داری، همین پوشه کافی است.
2. در نوار آدرس Chrome بنویس `chrome://extensions` و Enter بزن.
3. گزینهٔ **Developer mode** را روشن کن.
4. روی **Load unpacked** بزن و پوشهٔ **Rava** را انتخاب کن؛ همان پوشه‌ای که `manifest.json` داخلش است.
5. از منوی پازل Chrome، راوا را Pin کن. پنجرهٔ تنظیمات هنگام نصب باز می‌شود؛ بعداً هم از آیکون چرخ‌دندهٔ افزونه باز می‌شود.
6. تب‌هایی را که از قبل باز بوده‌اند یک بار Refresh کن.

فایل‌های پوشهٔ نصب را بعد از نصب جابه‌جا یا پاک نکن. این نسخه به‌صورت محلی نصب می‌شود و هنوز در Chrome Web Store منتشر نشده است. برای به‌روزرسانی، فایل‌های پوشه را جایگزین کن و در صفحهٔ افزونه‌ها روی Reload بزن؛ سپس تب‌های سایت را رفرش کن.

## اتصال به Google AI Studio

1. از [صفحهٔ کلیدهای Google AI Studio](https://aistudio.google.com/apikey) کلید بگیر.
2. کلید را فقط در تنظیمات افزونه، در کادر «کلید API گوگل» وارد کن.
3. برای سرعت، «انتخاب مدل پیشنهادی برای سرعت» را بزن. مدل پیش‌فرض `gemini-3.7-flash` است؛ دکمهٔ سرعت می‌تواند یک Flash-Lite در دسترس را پیشنهاد کند؛ می‌توانی شناسهٔ هر مدل متنی Gemini سازگار با `generateContent` را هم وارد کنی.
4. روی «تست واقعی ترجمه و ذخیرهٔ کلید» بزن. این دکمه فهرست مدل‌ها را می‌گیرد و جملهٔ «Hello! How are you?» را با مسیر اصلی ترجمه می‌کند. یک درخواست API مصرف می‌شود. اگر مدل انتخابی در فهرست نباشد، یک مدل متنی موجود انتخاب و نامش در فرم نمایش داده می‌شود.
5. فقط پس از موفقیت ترجمه، کلید و تنظیمات ذخیره می‌شوند. نتیجه و زمان تست را می‌بینی. حالا به سایت برگرد و متن را انتخاب کن؛ ترجمه در همان صفحه نمایش داده می‌شود. بخش آزمایش در تنظیمات هم اختیاری است.

استفاده از API تابع دسترسی، سهمیه و تعرفهٔ حساب گوگل خودت است. کلید داخل چت یا فایل‌های اشتراکی قرار نده.

## استفاده

- یک کلمه را دوبار کلیک کن یا یک جمله/پاراگراف را با ماوس یا کیبورد انتخاب کن. آیکون **RAVA** خودکار ظاهر می‌شود؛ با کلیک روی آن ترجمه در پاپ‌آپ همان صفحه نمایش داده می‌شود.
- لحن یا زبان را داخل پنجره عوض کن تا ترجمهٔ جدید بگیری. این تغییر در پنجرهٔ کنار متن موقت است.
- **توییتری:** محاوره‌ای و مناسب فضای شبکه‌های اجتماعی؛ بدون خلاصه‌کردن اجباری، شوخی یا ایموجی اضافه.
- **خودمونی:** شبیه حرف‌زدن طبیعی با یک دوست.
- **روان:** زبان طبیعی با لحن خنثی و وفادار به جزئیات.
- **رسمی:** مناسب ایمیل، کار و متن حرفه‌ای.
- در «سلیقهٔ خودت»، راهنمای دلخواه بنویس؛ مثلاً «اصطلاحات برنامه‌نویسی رو انگلیسی نگه دار».
- **Alt + Shift + T:** ترجمهٔ متن انتخاب‌شده. اگر میان‌بر با برنامه‌ای تداخل دارد، در `chrome://extensions/shortcuts` عوضش کن.
- **راست‌کلیک → Rava · ترجمه کن:** راه دیگر برای شروع ترجمهٔ متن انتخاب‌شده.
- **Escape:** بستن پنجره؛ **توقف:** قطع درخواست در حال اجرا.
- **کپی ترجمه** متن را کپی می‌کند. **ذخیرهٔ ترجمه** آن را در بخش ذخیره‌شده‌ها نگه می‌دارد.
- از آیکون راوا می‌توانی متن را مستقیم بچسبانی و ترجمه کنی. زبان و لحن انتخاب‌شده در این بخش، پیش‌فرض افزونه را به‌روز می‌کنند.
- برای توقف روی یک سایت، آیکون راوا را در همان سایت باز کن و «توقف در این سایت» را بزن. توقف برای همان نام میزبان است؛ زیر‌دامنه‌ها جدا هستند.

## زبان‌ها و ظاهر

رابط فارسی/انگلیسی، جهت راست‌به‌چپ/چپ‌به‌راست، و ظاهر روشن/تیره/هماهنگ با سیستم دارد. زبان مبدأ خودکار تشخیص داده می‌شود. مقصدها: فارسی، انگلیسی، عربی، ترکی، فرانسوی، آلمانی، اسپانیایی، روسی، ژاپنی، کره‌ای، چینی ساده، هندی، پرتغالی و ایتالیایی.

## داده‌ها و حریم خصوصی

- انتخاب متن به‌تنهایی هیچ درخواست ترجمه‌ای نمی‌فرستد. فقط با شروع ترجمه، همان متن به‌همراه دستور لحن/زبان به `generativelanguage.googleapis.com` فرستاده می‌شود. آدرس و کل محتوای صفحه در درخواست ترجمه نیست.
- کلید در فضای ذخیره‌سازی خود افزونه قرار می‌گیرد؛ در صفحهٔ وب، پاسخ‌های پیام‌رسانی یا همگام‌سازی Chrome قرار نمی‌گیرد. دسترسی اسکریپت‌های صفحهٔ افزونه به کلید محدود شده است.
- با روشن‌بودن «کلید روی این دستگاه بماند»، کلید در حافظهٔ محلی Chrome نگه داشته می‌شود؛ این فضای ذخیره‌سازی، رمزگذاری اختصاصی افزونه ندارد. با خاموش‌کردن آن، کلید فقط در نشست مرورگر می‌ماند و هنگام پایان نشست یا غیرفعال/Reload کردن افزونه پاک می‌شود.
- رمز ورودی‌های نوع password خوانده نمی‌شود. انتخاب در متن عادی، textarea و ورودی‌های متنی معمولی پشتیبانی می‌شود.
- تاریخچهٔ خودکار دائمی وجود ندارد. حداکثر ۳۰ نتیجه تا ۱۰ دقیقه در حافظهٔ موقت پردازش افزونه نگه داشته می‌شود؛ Chrome ممکن است آن را زودتر پاک کند. این حافظه برای کاهش درخواست تکراری است.
- فقط ترجمه‌هایی که خودت ذخیره کنی دائمی هستند: حداکثر ۱۰۰ مورد، شامل متن اصلی، ترجمه، زبان، لحن و زمان ذخیره؛ همگی قابل حذف‌اند.
- راوا سرویس تحلیل رفتار، تبلیغ یا سرور اختصاصی ندارد. پردازش متن توسط گوگل تابع [شرایط سرویس Gemini API](https://ai.google.dev/gemini-api/terms) است.

هر درخواست حداکثر ۱۲٬۰۰۰ نویسه دارد. راوا محتوای تصویر را تشخیص نمی‌دهد. خروجی مدل ممکن است خطا داشته باشد؛ کیفیت لحن به متن، مدل و تنظیمات وابسته است.

## اعتبارسنجی این نسخه

۱۷ تست هسته/API و ۳۱ بررسی اجرایی روی Chrome واقعی در یک پروفایل جدا پاس شدند. بررسی‌ها شامل آیکون با انتخاب واقعی ماوس، جلوگیری از هدایت به تب جدید، کلیک واقعی و کپی/Paste، تفکیک موفقیت فهرست مدل‌ها از موفقیت ترجمه، تنظیمات، جداسازی کلید، لغو درخواست، حافظهٔ موقت، پاسخ ناقص/مسدود، ذخیره/حذف، ایمنی نمایش HTML، حالت تیره و پنجره در عرض کم هستند.

پاسخ‌های Google در این بررسی‌ها شبیه‌سازی شدند. کلید واقعی، اتصال واقعی حساب و کیفیت زبانی خروجی واقعی هنوز آزمایش نشده‌اند. تصاویر پیش‌نمایش نیز از اجرای افزونه با همان پاسخ‌های شبیه‌سازی‌شده‌اند.

## For developers

No build step or runtime dependencies. `manifest.json` loads classic scripts into the isolated content-script world. `background.js` owns credentials, cache and persistent state. `api.js` provides one standard `generateContent` HTTP/JSON path for translations and connection probes. `core.js` contains prompts and validation. `content.js` mounts its own closed Shadow DOM and detects selection changes using capture listeners. `ui.js` shares the toolbar/settings translation UI.

API requests use a fixed Google endpoint, a key header, an explicit user action and `AbortController`. Untrusted source/model text is rendered through `textContent`. Local/session storage is restricted to `TRUSTED_CONTEXTS`; privileged app operations validate the sender. Preference mutations are serialized to avoid lost updates.

Run the dependency-free tests with Node 18+: `node --test tests/*.test.cjs`.

Implementation references: [Gemini content generation](https://ai.google.dev/api/generate-content), [available model discovery](https://ai.google.dev/api/models), [Chrome storage access control](https://developer.chrome.com/docs/extensions/reference/api/storage), [cross-origin requests](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests).
